# Sprint 2026-10-W3: one quic in the build graph

Chosen 2026-10-06 (option 1 of the plan after v0.5.2). Tasks live here,
not in GitHub issues.

## Why this sprint

A program cannot link http3-zig and capnp-zig (with `-Dquic=true`)
today, at any pin. http3-zig's `build.zig` makes its own quic module
from `quic_dep.path("src/root.zig")`. capnp-zig, qmsg, qmesh-zig and
nest take quic's exported module. Zig then sees the quic files in two
modules and stops: "file exists in modules 'quic0' and 'quic'"
(measured by the capnp-zig session on 2026-10-05). capnp-zig lists
http3-zig "for information only" until this is fixed.

## The shared option map

Zig makes one copy of a dependency only when every parent asks for it
with exactly the same options. The coordinated set uses:

```zig
b.dependency("quic", .{
    .target = target,
    .release = optimize != .debug,
    .@"sanitize-c" = @as([]const u8, "trap"),
})
```

and takes BoringSSL from quic's exported `boringssl` module.

## Rules

- Red first: a smoke test that copies capnp-zig's setup must fail on
  the old `build.zig`, then pass.
- Every gate before a push: core, cross (6 targets x 2 modes), interop,
  bench, both smoke tests.
- No release without the user.

      takes quic with the shared option map (like capnp-zig). Asserts
      one quic and one BoringSSL module, and passes the sibling's
      `*quic.Connection` type to `http3_zig.Session.init`.
- [x] Red on the old `build.zig`: "file exists in modules 'quic' and
      'quic0'", and BoringSSL linked twice. Green after C2 in Debug,
      ReleaseSafe and ReleaseFast (one `-Mquic=`, one `libssl.a`).

### C2. `build.zig` takes quic's exported modules

- [x] `quic` and `boringssl` from `b.dependency("quic", <shared map>)`.
      No own quic module, no quic `build_options` copy.
- [x] Dev tools (mem-profile, bench-e2e, wt-load) take their private
      ReleaseSafe set the same way (`.release = true`).

### C3. Pins and lint

      lint no longer checks a quic version string (gone with C2).
- [x] The sibling's quic pin must equal the root pin (lint; a planted
      mismatch fails).

### C4. CI and docs

- [x] CI runs the coexist smoke (Linux Debug and ReleaseSafe).
- [x] Embedding guide, README, root.zig docs: http3-zig with other
      quic packages.
